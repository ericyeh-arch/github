Python 開發環境入門

2026/05/16 早上課程大綱

本課程從 Google Colab 的雲端學習環境，延伸到正式本機開發流程，帶學生建立 VS Code、Python 虛擬環境、UV、Git 與 GitHub 的基本觀念。

本堂課重點

先把開發基本功打穩，再用 AI 輔助寫程式。學生需要理解專案、資料夾、終端機、虛擬環境與版本控制的關係，避免只記步驟卻不知道原因。

課程總覽

這堂課主要不是 Python 語法課，而是正式進入 Python 專案開發前的工具鏈建立。

一句話總結：一個專案就是一個資料夾；每個專案都應該有自己的開發環境，並能透過 GitHub 管理與同步。

課程主題

依照課堂內容整理成 12 個學習單元。

1學習方法與 AI 輔助

先建立基本功，再用 AI 產生程式碼並追問、理解與修正，不把 AI 當成完全黑盒。

2Google Colab

認識 Colab 檔案會存到 Google Drive，並了解它背後是雲端 Linux 執行環境。

3編輯器與開發環境

任何語言都需要編輯器與開發環境。Colab 適合學習，正式專案則需要本機工具。

4VS Code 安裝設定

安裝 VS Code、登入帳號、切換繁體中文、開啟自動儲存，並熟悉主要介面。

5專案資料夾

用資料夾管理專案，練習開啟、關閉、建立與刪除專案資料夾。

6整合式終端機

在 VS Code 中開啟終端機，確認所在目錄，並用指令查詢 Python 版本。

7Python 版本

不同專案可能需要不同 Python 版本與套件版本，因此不要讓所有專案共用同一套環境。

8UV 工具

使用 UV 建立與管理 Python 虛擬環境，並透過 uv --version 驗證安裝。

9初始化專案

使用 uv init 產生專案檔案，理解 pyproject.toml、README 與 Python 版本設定。

10虛擬環境

使用 uv venv 建立虛擬環境，進入環境後再用 Python 執行 main.py。

11GitHub Repository

建立 repository，命名避免中文與空白，加入 README 與 license，理解 public repo 的開源意義。

12Git 與 Clone

安裝 Git for Windows，透過 VS Code 從 GitHub clone 專案到本機，之後只需開啟本機資料夾。

課後練習清單

照這份清單確認自己是否已經能獨立完成基本開發流程。

  • 安裝並開啟 VS Code，完成繁體中文與自動儲存設定。
  • 建立一個專案資料夾，並用 VS Code 開啟它。
  • 在 VS Code 中開啟整合式終端機，確認目前目錄。
  • 安裝 UV，並用 uv --version 確認成功。
  • 在專案資料夾中執行 uv init。
  • 執行 uv venv 建立虛擬環境。
  • 進入虛擬環境後執行 python main.py。
  • 建立 GitHub repository，並用 VS Code clone 到本機。
